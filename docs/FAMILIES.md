# Canonical Families

Each bundle (`<stage>/<bodyType>`) authors one asset per family listed here. The file is named
after the family: family `bob` lives at `.../hair/bob.svg` with `data-family="bob"`.

Interpret each family for the age you are drawing — a `hoodie` on a newborn is a hooded onesie
top, on a grandparent it is a looser zip-up. Same family, same slot, age-appropriate art.
